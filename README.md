## Proyectos


### Elder Companion
**Sistema de Asistencia Virtual**

Aplicación móvil conectada con dispositivos electrónicos para apoyar el seguimiento de información de adultos mayores y facilitar su consulta por familiares y cuidadores.

- Desarrollo de aplicación móvil para Android.
- Integración de dispositivos electrónicos basados en ESP32.
- Comunicación Bluetooth Low Energy (BLE) para transmisión de información.

**Tecnologías:** Kotlin, Android Studio, ESP32 y BLE.

### Sistema de Alerta y Pánico para Conductores

Aplicación móvil diseñada para enviar alertas de emergencia y compartir la ubicación en tiempo real con contactos previamente registrados.

- Desarrollo de aplicación Android.
- Integración de un botón físico de emergencia mediante ESP32.
- Envío de alertas y compartición de ubicación.

**Tecnologías:** Kotlin, Android Studio y ESP32.

### Traductor de Lenguaje de Señas mediante Reconocimiento de Gestos

Sistema de reconocimiento de gestos desarrollado mediante procesamiento de imágenes y técnicas de aprendizaje automático.

- Recolección de secuencias de imágenes para representar señas.
- Detección de puntos de referencia corporales mediante MediaPipe.
- Construcción de conjuntos de datos y entrenamiento de modelos con TensorFlow.
- Exportación del modelo entrenado en formato H5.

**Tecnologías:** Python, MediaPipe y TensorFlow.
